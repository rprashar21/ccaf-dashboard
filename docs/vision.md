A certification prep platform for CCA-F (and beyond) — a public-facing quiz app where people can practice questions, track their score/accuracy over time, and see a per-domain breakdown (agentic loops, hooks, orchestration, etc.), instead of a static PDF or one-off HTML file.
User-contributed content that grows over time — you (and later others) can add cert prep sources — PDFs, text, URLs — and the app processes them into new draft questions automatically, rather than every question being hand-typed.
Coding exercises alongside the quiz questions — not just multiple choice; hands-on coding problems that run against real test cases in a sandbox, so the platform covers both knowledge recall and applied skill.
Two things happening under the hood: a fast web app (Next.js) for everything people click and see, and a separate Python agent-service running in the background for the slow, multi-step work — turning a raw PDF into draft questions, or turning test results into written feedback on a code submission — so the site itself never slows down waiting on that.
Draft-then-review, not fully automatic — anything the ingestion agent generates lands as a draft, not live content; you review and approve before it's shown to real users. Deterministic checks (4 options present, no duplicates, has an explanation) filter obvious junk before it even reaches you.
Underneath all of that: Postgres for the data, Docker for local dev, GitHub Actions for CI so nothing broken reaches main, and Vercel/Railway (or similar) for actually hosting the two pieces once you're ready to go live.
